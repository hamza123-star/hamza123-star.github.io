🧰 Why Do You Need gemini-router?

If you use Google Gemini or Antigravity CLI on your Linux computer, you've probably hit frustrating limits. Maybe your requests were too fast, or you reached a daily quota. gemini-router solves these problems automatically!

🔄 Smart Load Balancing

Automatically distributes your requests across multiple Gemini accounts. No more getting blocked or limited!

📊 Quota Management

Tracks each account's usage in real-time. Stops requests before hitting limits, so you won't face shutdowns.

⏱️ Adaptive Rate Limits

Automatically adjusts request speed based on how the API responds. Fast when possible, slower when needed.

🔄 Auto Retrying

If a request fails, it automatically retries on a different account. No more wasted work or interruptions.

🚀 Quick Start Guide

# First, make the file executable
chmod +x gemini-router

# Start the router
./gemini-router start

# Add your first account
gemini-router add-account --name "My Gemini Account"

# Run a sample request
gemini-router run "Hello, how are you?"

That's it! gemini-router will handle everything in the background. You can continue using your normal Gemini commands while the router optimizes all traffic.

❓ Frequently Asked Questions

Is it safe to use?

Absolutely! gemini-router runs entirely on your computer. It doesn't send data anywhere except to the Gemini API you're already using.

Do I need multiple accounts?

No, it works great with a single account too. It will just manage your rate limits more efficiently, preventing those annoying "too many requests" messages.

Will it slow down my computer?

Not noticeably. gemini-router is lightweight and runs quietly in the background. You'll probably forget it's even there!

Can I use it with other AI tools?

Currently optimized for Gemini CLI and Antigravity. Future versions may support more providers.
